로컬 데이터

복구 범위

데이터 변경과 입력창 값을 같은 브라우저·같은 주소의 IndexedDB에 임시 저장합니다. 다음 접속에서는 복구본을 명시적으로 선택합니다. 다른 탭은 각각 별도 복구본을 만들며 서로 덮어쓰지 않습니다. Undo 이력과 화면 설정은 복원하지 않습니다.

서버 저장은 요청 ID를 브라우저에 기록한 뒤 전송합니다. 응답이 끊기거나 저장 중 종료되면 같은 요청으로 결과를 다시 확인합니다. 복구 버튼이 서버 저장을 자동 실행하지는 않습니다.

이 예제는 demo 계정/품목이라는 고정 복구 키를 사용합니다. 실제 앱에서는 로그인 사용자·업무 데이터별 키를 지정하세요. 브라우저 데이터 삭제, 저장소 차단·용량 초과, 저장 완료 전 종료와 전원 장애에서는 복구를 보장하지 않습니다. 임시 저장 실패 시 상태 영역에서 확인하고 복구본을 내려받을 수 있습니다.

node scripts/serve.mjs로 HTTP 서버를 실행하세요. 로컬 기준점 확정은 호스트 저장 성공 뒤 markSaved()를 호출하는 동작의 예시이며 서버 저장이 아닙니다. 서버 모드는 로컬 예제 JSON 저장소를 사용합니다.
