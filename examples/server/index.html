서버 목록 조회

이 예제는 조회 전용입니다. 페이지마다 원본을 다시 읽으며, 복사와 Excel 다운로드를 지원합니다. 변경 저장 API는 별도로 연결해야 합니다.

지연·실패는 이 예제에서만 사용하는 통신 테스트입니다.

서버 연동 규칙

검색·정렬·필터는 서버의 전체 목록에 적용합니다. 조건을 바꾸면 첫 구간부터 조회하며 이전 요청을 취소합니다. 실패하면 이전에 읽은 구간을 보존하고 ‘다시 시도’를 제공합니다. 무한 스크롤의 같은 구간을 중복으로 요청하지 않습니다.

현재 페이지·불러온 행·선택 영역은 화면에 읽어온 값으로 Excel을 만듭니다. 검색 결과와 전체 다운로드는 별도 서버 exportRows 연결을 통해 전체 행을 받아 만듭니다. 이 예제는 두 콜백을 모두 제공합니다.

이 화면은 Node가 제공하는 HTTP 서버에서 열어야 합니다. 저장소에서 node scripts/serve.mjs를 실행한 뒤 http://127.0.0.1:4173/examples/server/index.html로 접속하세요. 폐쇄망에서는 같은 파일과 API를 내부 서버에 배포합니다.

서버 인증·DB·변경 저장·다중 사용자 동시 편집은 호스트의 역할입니다. 예제 API는 루프백 주소에서 예시 데이터만 제공합니다. 사용자 인증정보나 유료 그리드 코드를 포함하지 않습니다.
