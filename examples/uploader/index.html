MOUM / UPLOADER 0.2.0

파일을 올리기 전에, 데이터를 먼저.

엑셀·CSV를 읽고 시트와 열을 연결하세요. 원본 행과 검증 결과를 확인한 뒤 필요한 데이터만 가져갈 수 있습니다.

이 예제는 로컬 검토 모드입니다. 실제 서버로 전송하지 않습니다. 정상·오류 예제로 파싱과 검증을 확인하세요.

기본 제한은 파일 20MB·10개, 데이터 10,000행·200열입니다. 헤더 번호는 원본 행 번호이며 0은 헤더 없음을 뜻합니다. Excel 수식은 실행하지 않고 저장된 계산 결과만 읽습니다. CSV는 UTF-8을 기본으로 사용합니다.

검증된 데이터가 여기에 표시됩니다.
