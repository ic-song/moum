물품 등록·편집

Excel 셀을 복사해 Ctrl+V로 붙여넣으세요. 일반 모드에서는 부족한 행이 자동 추가됩니다. Shift+헤더 클릭은 다중 정렬, 헤더 오른쪽 경계는 너비 조절입니다.

품목코드·상위코드는 읽기 전용입니다. 수량·단가에는 쉼표가 포함된 숫자도 입력할 수 있습니다. 열 범위를 넘거나 유효하지 않은 값이 있으면 전체 작업을 취소합니다. 그룹·트리·검색·필터 상태에서는 붙여넣기로 행을 자동 추가하지 않습니다.

일반 모드에서 여러 셀을 선택하고 병합할 수 있습니다. 병합 중 가려진 원본 값은 보존되며 붙여넣기 전에는 병합을 해제해야 합니다. XLSX 가져오기는 첫 행의 컬럼명으로 매핑하고 기존 데이터를 교체하며 Ctrl+Z로 원복할 수 있습니다.

macOS에서는 Ctrl 대신 ⌘를 사용합니다. 셀 안에서 문자를 편집하는 동안에는 기본 텍스트 복사·붙여넣기와 실행 취소가 동작합니다. 변경은 메모리에만 유지되며 새로고침하면 초기화됩니다.

서버 편집·저장 예제 · 서버 데이터 예제 (HTTP 실행 필요) · MOUM는 독립 구현하는 JavaScript 도구 모음입니다. RealGrid의 구현 코드와 리소스를 포함하지 않습니다. XLSX 기능은 동봉한 SheetJS Community Edition(Apache-2.0)을 사용합니다. 가상 스크롤·수식·API 일부 이행 예제도 확인하세요. 전체 RealGrid 호환은 제공하지 않습니다.
