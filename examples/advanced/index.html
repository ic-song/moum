같은 데이터 공급자에 연결된 두 번째 화면입니다. 한쪽에서 편집하면 함께 갱신됩니다.

계산과 편집 규칙

수식 예제의 D열은 =B1*C1로 금액을 계산합니다. F2로 원문을 편집하고 Ctrl+Z/Y로 되돌리거나 다시 실행할 수 있습니다. A1은 검색·정렬 전 원본 데이터의 첫 행·첫 열입니다. 화면 순서가 바뀌어도 참조 위치는 유지됩니다.

SUM·AVERAGE·MIN·MAX·COUNT·COUNTA·IF·AND·OR·NOT·ABS·ROUND·CONCAT을 지원합니다. 순환 참조와 0 나누기는 셀에 오류를 표시합니다. 전체 Excel 수식 문법과 동일하지는 않습니다.

가상 스크롤에서는 필요한 셀만 화면에 만듭니다. Ctrl+End로 마지막 셀에 이동하고 Shift+방향키로 화면 밖까지 선택해 보세요. 행 높이는 48px로 고정하며 수동 병합은 제공하지 않습니다.

엑셀 다운로드는 현재 페이지·불러온 행, 검색·정렬 결과, 전체 데이터, 선택 영역 중 고를 수 있습니다. 수식 보존은 코드에서 exportXLSX({ scope: 'all', formulas: true })로 사용하며, 가져올 파일의 컬럼 순서는 예제와 같아야 합니다. 행 삽입·삭제 시 A1 주소 자체는 다시 쓰지 않습니다.

무한 스크롤은 로컬 데이터를 하단에서 일정 행씩 더 표시합니다. 페이징은 페이지 번호·이전/다음·행 수로 이동합니다. 검색·정렬·필터를 바꾸면 처음부터 표시합니다. 그룹 제목과 소계도 표시 행 수에 포함되며, 선택·Ctrl+A·복사는 현재 페이지 또는 불러온 행에 적용됩니다.
