변경과 저장

행 번호의 +는 추가, *는 수정한 미저장 행입니다. 삭제한 행 수는 연결 상태에 표시됩니다. 저장·취소 전에는 페이지, 검색, 필터, 무한 스크롤 구간을 바꾸지 않습니다. 코드와 행 버전은 서버가 관리합니다.

저장 실패 시 입력은 유지됩니다. 다른 사용자가 같은 행을 바꾸면 덮어쓰지 않습니다. ‘변경 취소’로 최신 데이터를 다시 읽은 뒤 수정하세요. 응답이 끊기면 ‘저장 결과 다시 확인’이 같은 요청 ID로 결과를 확인합니다.

node scripts/serve.mjs로 실행합니다. 예제는 output/server-data/store.json에 행과 저장 결과를 기록하므로 서버를 재시작해도 유지됩니다. 현재 페이지·선택 영역 Excel에는 미저장 값도 포함됩니다. 전체·검색 결과 Excel은 저장 후 사용하세요.

이 서버는 로컬 개발용 단일 프로세스 예제입니다. 실제 서비스는 인증·권한 검사와 DB 트랜잭션을 dataSource 콜백에 연결하세요. 브라우저를 강제로 닫으면 미저장 입력은 복구되지 않습니다.
