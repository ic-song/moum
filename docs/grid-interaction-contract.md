# 셀 조작 계약

사용자 지정 필수 요구사항을 첫 버전의 기준으로 고정합니다. 아래 단축키는 그리드 셀에 포커스가 있고 입력창 편집 중이 아닐 때 적용합니다.

| ID | 입력 | 결과 | 확인 기준 |
| --- | --- | --- | --- |
| UX-01 | 마우스 드래그 | 시작 셀과 끝 셀 사이 직사각형 선택 | 가로·세로·역방향 선택, 범위 강조 |
| UX-02 | Shift+방향키 | 최초 기준점 유지, 현재 셀 이동 | 선택 확대와 반대 방향 축소 |
| UX-03 | Ctrl+C | 선택 범위를 text/plain TSV로 복사 | 행은 CRLF, 열은 탭; 셀 내부 구분문자는 따옴표 처리 |
| UX-04 | Ctrl+V | 왼쪽 위부터 여러 셀 붙여넣기 | 2행×2열 한 번 적용, 숫자 변환, 읽기 전용 보호 |
| UX-05 | Delete | 선택 셀 값 일괄 지우기 | 행을 삭제하지 않으며 숫자는 null, 문자열은 빈 값 |
| UX-06 | Ctrl+Z | 가장 최근 데이터 작업 전체 취소 | 붙여넣기 또는 Delete 여러 셀이 한 번에 원복 |
| UX-07 | Ctrl+Y | 취소된 작업 전체 재실행 | Ctrl+Z→Ctrl+Y 후 모든 값 복원 |
| UX-08 | 새 편집 후 Ctrl+Y | 이전 재실행 이력 폐기 | 취소했던 과거 작업이 다시 적용되지 않음 |

macOS에서는 ⌘를 사용하고 다시 실행에 ⌘+Shift+Z도 지원합니다. 브라우저 입력창에서 문자를 편집 중일 때는 기본 텍스트 편집 동작을 유지합니다.

## 원자성과 보호 규칙

1. 변경 후보 전체를 수집합니다. 검색·정렬 후 표시 좌표를 원본 행 인덱스로 변환합니다.
2. 읽기 전용 셀은 그대로 두고 편집 가능한 셀만 검증합니다. 전체 읽기 전용 그리드는 변경하지 않습니다.
3. 잘못된 값 또는 required 오류가 있으면 **변경 전 상태를 그대로 유지**하고 오류를 안내합니다. 변경 이력도 추가하지 않습니다.
4. 통과한 변경을 한 번에 반영하고 Undo 이력 한 건을 기록합니다. 읽기 전용 셀과 동일한 값은 이력에 기록하지 않습니다.
5. Undo/Redo에서도 원본 행 인덱스를 사용해 정렬·검색과 데이터가 섞이지 않도록 합니다. `setData`는 새 데이터 기준으로 이력을 제거합니다.

예: B2:C4에 6개 값을 붙여넣고 Delete를 누르면 이력은 `붙여넣기`, `지우기` 두 건입니다. Ctrl+Z는 6개 값을 되살리고, 한 번 더 누르면 붙여넣기 전 값으로 복원합니다. Ctrl+Y는 같은 순서로 다시 적용합니다.

## 첫 버전의 범위

- 단일 직사각형만 지원합니다. 여러 비연속 영역·병합 셀·숨김 컬럼은 후속 기능입니다.
- 붙여넣기는 선택 크기를 반복 채우지 않고 선택 왼쪽 위부터 원본 TSV 크기대로 적용합니다.
- 열 범위를 넘는 데이터는 전체 거부합니다. 일반 무필터 모드에서는 부족한 행을 자동 추가하고, 그 행까지 붙여넣기 Undo/Redo 한 건으로 처리합니다. 그룹·트리·검색·조건 필터 상태 또는 pasteAppend:false이면 행 범위 초과도 거부합니다.
- 드래그 중 화면 밖으로 자동 스크롤하는 기능은 아직 없습니다. 현재 보이는 셀 사이에서 선택하거나 Shift+방향키를 사용합니다.
- Excel HTML과 TSV를 함께 읽고 셀 내부 CRLF는 LF로 정규화합니다. 텍스트의 탭·앞자리 0을 유지하고 숫자 컬럼은 원시 숫자 또는 유효한 쉼표 숫자를 변환합니다.
- 로컬 XLSX 파일 입출력과 파일 전체 교체 Undo/Redo를 지원합니다. 외부 모듈은 로컬로 동봉합니다.
- 실제 Excel이 만든 파일과 복사 범위 데이터로 검사했습니다. 사용자의 Excel→브라우저 직접 수동 키 입력, 한글 IME와 macOS 실기기 단축키는 추가 수용시험 대상입니다.

## 고급 기능의 조합

정렬·필터·그룹·트리의 표시 행은 원본 인덱스로 매핑합니다. 그룹 소계·트리 expander 자체는 데이터 셀 범위에 포함하지 않습니다. 트리 부모 행을 삭제하면 숨겨진 자손도 같은 데이터 트랜잭션에서 삭제하고 함께 복원합니다. 그룹·트리는 별도 모드이며 트리 검색·필터는 일치 노드의 상위 경로를 함께 표시합니다.

수동 병합은 일반 모드에서 사용합니다. 선택이 병합 영역과 겹치면 전체 병합 범위로 확대하고 Delete/Undo도 해당 범위 전체에 적용합니다. 직접 편집은 좌상단 셀만 변경하며 가려진 값은 보존합니다. 붙여넣기는 병합을 해제한 뒤 수행하고 고정 열 경계를 넘는 병합은 거부합니다. 뷰 변경은 데이터 Undo 이력에 포함하지 않습니다.

## 공식 참고

[키보드·마우스 동작](https://docs.realgrid.com/tutorial/defaultKeyboardAndMouseControll), [복사·붙여넣기](https://docs.realgrid.com/guides/editing/copy-and-paste), [Undo/Redo](https://docs.realgrid.com/guides/editing/undo)를 참고해 요구사항을 작성했습니다. Delete의 읽기 전용·트랜잭션 정책 등은 MOUM가 채택한 설계이며 RealGrid와 모든 옵션이 동일하다는 의미는 아닙니다.

## 0.3 확장 계약

가상화 여부와 무관하게 범위 조작은 전체 표시 데이터에 적용합니다. 수식 모드에서는 편집·이력에 원문을 보관하고 표시·일반 복사에 계산값을 사용합니다. 내부 복사의 상대/절대 참조, XLSX 보존, IME 조합과 외부 데이터 경합 규칙은 [확장 API](grid-advanced.md)에 정의합니다. 가상 모드는 48px 고정 높이를 사용하고 수동 병합은 거부합니다.

## 0.4 표시 범위

페이징·무한 모드의 선택·Ctrl+A/C·Delete·붙여넣기는 현재 페이지/불러온 행에만 적용합니다. 페이지 변경은 선택만 초기화하고 원본과 이력을 보존합니다. 범위 초과 붙여넣기는 거부합니다. 표시 방식·다운로드 계약은 [data-modes.md](data-modes.md)에 있습니다.

## 0.5 서버 조회

dataSource 서버 모드는 조회 전용이며 셀/행 변경·붙여넣기·가져오기를 거부합니다. 로컬 편집 계약은 그대로 유지합니다. 서버 선택·범위 복사·전체/현재/선택 Excel과 비동기 요청 규칙은 [서버 API](server-data.md)를 따릅니다.
