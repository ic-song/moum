# MOUM 개발 로드맵

## MOUM의 개발 방향

MOUM은 웹 화면에서 반복해서 필요한 데이터 표시·입력·탐색·일정 기능을 독립 JavaScript 패키지로 제공합니다. 개인 도구, 교육·연구, 커뮤니티, 기업 시스템에 같은 API를 적용할 수 있도록 개발합니다.

- 여러 용도에서 공통으로 쓰이는 동작은 코어에서 제공합니다. 데이터와 화면 설정을 분리하고 필요한 기능을 조합할 수 있게 합니다.
- 분야별 상태명, 저장, 인증, 권한, 외부 시스템 연동은 사용하는 앱에서 연결합니다. 분할 납품처럼 특정 업무에 필요한 계산은 선택해서 호출하는 함수로 제공합니다.
- 신규 기능은 두 가지 이상의 적용 사례로 설계를 확인합니다. 기본 사용법, 키보드·접근성, 대용량에서의 동작, TypeScript와 오프라인 배포까지 검증 범위에 반영합니다.

## 그리드

MOUM Grid는 설문 응답, 개인 목록, 연구 데이터, 운영 현황 등 표 형식 자료를 조회·편집·검증하는 데 사용합니다. 데이터와 열 배치를 분리해 동일한 자료를 사용자나 화면별로 구성할 수 있게 합니다.

첫 단계로 열 숨김·순서·너비를 읽고 복원하는 API를 제공합니다. 다음 기능은 다단 헤더와 날짜·선택 목록 편집기를 우선 검토합니다. 기존 그리드 이관에는 별도의 공개 API 일부 이행 계층을 유지합니다.

## 차트

MOUM Charts는 관측값 추이, 활동 통계, 설문 구성비 등 숫자 자료를 보여 줍니다. 계열과 원본표 보기를 저장하고 SVG·PNG로 내보낼 수 있습니다. 기준선·목표 표시와 대량 데이터 표시 방식은 서로 다른 데이터 예제로 검토합니다.

## 간트

MOUM Gantt는 행사 준비, 학습 계획, 제작 일정, 프로젝트 진행을 전체 화면이나 미니 보기로 표시합니다. 작업 계층·선후행·기준 일정·마감일은 여러 용도에서 재사용할 수 있습니다. 예를 들어 전시 공간 배치와 홍보 준비는 SS 관계로 병행하고, 설치 완료 후 안전 점검은 FS 관계로 연결할 수 있습니다.

## 업로더와 캘린더

업로더는 사진·문서 첨부부터 표 데이터 검토까지 동일한 큐를 사용합니다. 전체 용량 제한과 중복 정책은 앱에서 선택합니다. 캘린더는 수업, 모임, 시설 예약, 개인 일정에서 날짜·보기·주 시작 요일·자원 필터를 저장하고 복원할 수 있습니다. [업로더 API](../packages/uploader/README.md) · [캘린더 API](../packages/calendar/README.md)

## 그리드 0.8 진행 반영

Grid/GridModel의 `validate()`로 모델의 필수값·변환·사용자 검증·수식 오류를 모읍니다. `validateRow`로 같은 행의 여러 값을 비교할 수 있습니다. 공개 API와 이행 계층의 TypeScript 선언을 tgz로 제공합니다. [입력 검증·타입](grid-validation-types.md) · [컴포넌트 현황](components.md)

## 0.2.0 반영 상태

Excel HTML/TSV 붙여넣기·자동 행 확장, 행 추가/삭제·파일 교체 Undo/Redo, 조건 필터 AND/OR, 다중 정렬, 왼쪽 열 고정·너비 조절, 다단 그룹·숫자 소계, ID/부모 ID 트리, 수동 사각형 병합, XLSX 입출력을 기본 구현했습니다. 아래 M0~M3는 당초의 전체 후보 분류이며 단계에 속한 모든 기능이 완료되었다는 뜻은 아닙니다. 최신 상태는 카탈로그의 기능 ID별 상태와 [비교표](realgrid-comparison.md)를 기준으로 합니다.

## 기능 참고 기준

2026-11-15에 [RealGrid2 공식 가이드](https://docs.realgrid.com/)와 [버전 기록](https://docs.realgrid.com/changelog/releases)을 확인했습니다. 참고 릴리스는 2.10.2(2026-10-22)이며 사용자의 실제 적용 버전은 미확인입니다. 예전 RealGridJS 1.x 자료와 현재 RealGrid2 기능을 같은 버전으로 취급하지 않습니다.

기능 카탈로그는 **공식 기능 후보 + 자체 요구사항 + 관련 제품 확장 후보**입니다. 모든 메서드·콜백·옵션을 열거하거나 완전한 API 호환을 약속하지 않습니다. 각 기능의 상세 구현에 착수할 때 본문·제약·이벤트 순서와 상호작용을 추가 분석합니다. 현재 완성도 백분율은 산정하지 않습니다.

## M0 · 핵심 셀 조작

현재 초기 구현의 범위입니다. 모델과 DOM을 분리하고, 데이터 타입·검증·범위 선택·클립보드·Delete·Undo/Redo를 하나의 변경 모델 위에 구현합니다. 브라우저 JS·CSS 배포물과 오프라인 예제를 포함합니다. 접근성과 IME는 별도 실기기 검증까지 마무리해야 합니다.

필수 수용 시나리오는 [셀 조작 계약](grid-interaction-contract.md)의 UX-01~08입니다. 모델 테스트에 더해 실제 브라우저 키·마우스 입력, 검색·정렬 후 원본 행 매핑, 외부 HTTP 요청 차단 상태를 확인합니다.

## M1 · 업무에 적용하는 그리드

행 추가·삭제·변경 상태·저장 기준 롤백, 고유값·조건 필터, 다중 정렬, 컬럼 너비·순서·고정 열, 그룹 헤더, 드롭다운·날짜 편집기, 행·전체 검증, 로컬 페이징과 기본 집계를 구현합니다. TypeScript 선언과 공개 API 계약을 정리합니다.

XLSX는 0.2.0에서 SheetJS Community Edition 0.20.3(Apache-2.0)을 로컬 동봉하는 선택 모듈로 추가했습니다. [RealGrid 내보내기 문서](https://docs.realgrid.com/guides/excels/excel-export)는 JSZip을 요구하고, [가져오기 예제](https://docs.realgrid.com/guides/tip/excel-import)는 SheetJS를 사용합니다. MOUM는 동봉 파일과 라이선스·해시를 제공하고 런타임 CDN을 요구하지 않습니다. 정교한 엑셀 스타일·수식·보호는 후속 대상입니다.

## M2 · 고급 그리드

행·열 가상 스크롤, 대량 데이터 공급 콜백, 다단 행 그룹·소계, 세로 병합, 트리 모델, 렌더러·편집기 확장, 개인화 상태 저장, React·Vue 어댑터를 진행합니다. 첫 모델에서부터 화면 인덱스와 데이터 인덱스를 분리하므로 렌더링 전략을 교체해도 변경 이력을 유지할 수 있게 발전시킵니다.

성능 기준은 실측 전까지 확정하지 않습니다. 1만·10만 행과 여러 열 수의 고정 데이터셋으로 최초 표시·스크롤·검색·정렬·붙여넣기·메모리 사용량을 기록하고 환경을 함께 공개하는 벤치마크를 작성할 예정입니다.

## M3 · 특수 기능과 이행

복합 세로 레이아웃·가로 병합·병합 일괄 편집, 트리 지연 로드·노드 이동, 엑셀 보호·메모·수식·이미지 출력, 스파크라인·바코드, 그리드 간 드래그를 다룹니다. 엑셀식 자유 셀 참조 수식 엔진과 채우기 핸들은 자체 확장 후보로 분리합니다.

RealGrid 이행 어댑터는 실제 기존 프로젝트의 API 사용 목록을 확보한 후 지원 메서드·기본값·좌표·이벤트·오류 동작별로 호환 테스트를 작성합니다. 코어 API와 분리하고 미지원 기능을 조용히 무시하지 않습니다.

## 이후 독립 라이브러리 확장

그리드에서 실제로 재사용되는 검증·편집기·트리·다이얼로그·날짜 선택 UI를 필요에 따라 독립 패키지로 분리합니다. 피벗·차트·리포트·지도는 관련 제품 연동을 참고하는 별도 후보이며 첫 Grid 모듈에 함께 완성된 것으로 표시하지 않습니다.

## 배포·검증 원칙

- 기본 모듈은 외부 런타임 의존성 없이 실행합니다. XLSX 같은 선택 의존성은 모듈 경계와 로컬 배포 목록을 명시합니다.
- 일반 script·ESM·CommonJS를 제공하고 소스와 빌드 산출물을 함께 관리합니다. npm 등록은 별도 작업입니다.
- 런타임에서 CDN·온라인 인증·외부 폰트·분석 요청을 만들지 않습니다. 호스트가 제공하는 내부 API 콜백은 별도입니다.
- 새로 구현한 기능은 카탈로그 상태와 검증 증거를 함께 갱신합니다. 실제 Excel 왕복·스크린리더·IME·다중 브라우저와 대용량 성능은 확인한 범위만 표시합니다.
- RealGrid의 내부 구현·라이선스 파일·브랜드 자산을 포함하지 않습니다. 참고 문서의 기능과 관찰 가능한 동작을 자체 코드로 구현합니다.

## 0.3 진행 반영

행·열 가상 스크롤, opt-in A1 수식 일부와 XLSX 수식 보존, 공개 API 일부 이행 계층을 구현했습니다. 기준 프로젝트가 없어 RealGrid2 공개 API를 참고하고 지원 인수·차이를 [이행 지원표](realgrid-api-subset.md)에 고정했습니다. Windows 네이티브 IME·타 엔진·전체 메모리·기존 RealGrid 실행본 대조와 나머지 API는 미완료입니다. [확장 API](grid-advanced.md)의 범위가 이전 단계의 포괄적 계획보다 우선합니다.

## 0.4 진행 반영

로컬 페이징·로컬 데이터 무한 스크롤·표시 방식 선택·네 가지 범위의 Excel 다운로드를 구현했습니다. 서버 데이터 공급·서버 페이징은 계획 상태입니다. [이번 API 계약](data-modes.md)이 이전 계획보다 우선합니다.

## 0.5 진행 반영

조회전용 서버 페이징·무한 스크롤·서버 검색/정렬/필터·취소/경합/시간초과/재시도와 별도 서버 전체 Excel 콜백을 구현했습니다. 서버 예제는 실제 HTTP로 예시 데이터를 제공하며 운영 DB/인증/저장 통합은 호스트 범위입니다. 서버 시나리오·로컬 핵심 편집을 3엔진에서 검사했고 자동 접근성 검사를 보강했습니다. [현재 서버 계약](server-data.md)이 이전 단계의 계획보다 우선합니다.
