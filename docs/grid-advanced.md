# 0.3 확장 API

예제는 [advanced/index.html](../examples/advanced/index.html)입니다. 기본 그리드와 같은 로컬 JS·CSS를 사용합니다.

## 행·열 가상 스크롤

표시 결과가 200행을 넘으면 행을, 컬럼이 30개를 넘으면 열을 가상화합니다. `virtual:false`로 끌 수 있습니다. 화면에 보이는 셀 주변만 DOM에 만들고, 선택·복사·붙여넣기·Delete·Undo/Redo는 전체 데이터와 표시 좌표를 사용합니다. 왼쪽 고정 열은 계속 표시합니다. Ctrl+Home/End로 처음·끝에 이동할 수 있습니다.

가상 모드 행 높이는 48px, 헤더는 약 56px입니다. 긴 표시 값은 한 줄로 줄여 보이며 F2로 전체 값을 편집합니다. 그룹·소계와 트리도 표시 행 창을 사용합니다. 수동 사각형 병합은 가상 모드에서 거부하며, 가상화 임계값을 넘는 데이터로 변경하면 기존 병합을 해제합니다. 편집·IME 조합 중에는 입력 DOM을 유지하기 위해 스크롤 재렌더링을 보류합니다. 드래그로 화면 가장자리에 도달했을 때의 자동 스크롤은 아직 없습니다.

검증 데이터는 10만 행×12열과 1천 행×200열입니다. 지원 범위의 권장 상한은 그룹·소계 포함 표시 행 20만 개입니다. 그보다 큰 결과는 호스트에서 나누어 공급하세요. 브라우저의 최대 스크롤 높이는 유한하며 무제한 행을 지원하지 않습니다. 전체 데이터·검색·정렬은 메모리에서 처리하고, 구조 변경 이력은 행 스냅샷을 보관합니다. DOM 감소가 데이터 메모리 감소나 서버 페이징을 뜻하지는 않습니다. 실측 환경과 시간은 [검증 기록](verification.md)에 있습니다.

## 수식

기본값은 수식 비활성화입니다. 기존 문자열 `=...`을 그대로 보관하는 동작을 유지합니다.

```js
const grid = new MoumGrid('#grid', {
  formulas: true,
  columns: [
    { field: 'quantity', type: 'number' },
    { field: 'price', type: 'number' },
    { field: 'amount', type: 'number' }
  ],
  data: [{ quantity: 2, price: 3000, amount: '=A1*B1' }]
});
grid.getData();              // amount: 6000
grid.getData({ raw: true }); // amount: '=A1*B1'
```

필드별 `formulas:false`로 수식을 막을 수 있습니다. A1 주소의 행·열은 **원본 데이터 배열과 모델의 컬럼 순서**입니다. 첫 데이터 행이 1행이고 헤더는 포함하지 않습니다. 검색·정렬·그룹·트리 접기 후에도 주소는 바뀌지 않습니다. 행 삽입·삭제 시 기존 주소 문자열을 재작성하지 않으므로 주소가 가리키는 행은 바뀔 수 있습니다. 구조 이력 Undo는 원문을 복원합니다.

| 지원 | 내용 |
| --- | --- |
| 참조 | `A1`, `$A$1`, `A$1`, `$A1`, `A1:B10` |
| 값·연산 | 숫자, 큰따옴표 문자열, TRUE/FALSE, 괄호, `+ - * / ^ % &`, `= <> < > <= >=` |
| 함수 | SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, IF, AND, OR, NOT, ABS, ROUND, CONCAT |
| 오류 | `#PARSE!`, `#NAME?`, `#REF!`, `#CYCLE!`, `#DIV/0!`, `#VALUE!`, `#NUM!`, `#LIMIT!` |

IF는 선택한 가지를 계산합니다. 집계 함수는 범위의 숫자만 집계하며 ROUND는 최대 ±15자리입니다. 문자열을 숫자로 자동 해석하는 Excel의 모든 강제 변환 규칙을 구현하지 않습니다. 날짜·다른 시트·외부 통합 문서·이름 정의·배열 수식·동적 배열·구조화 참조·로캘별 세미콜론은 지원하지 않습니다. 미지원 문법과 함수는 오류 셀로 보입니다. 원문 4,096자, 토큰 1,024개, 참조 깊이 128, 한 범위 10만 셀로 제한합니다. JavaScript `eval`이나 외부 요청을 사용하지 않습니다.

편집 후 의존값을 다시 계산하고 검색·정렬·필터·그룹 합계에는 계산값을 사용합니다. 계산값이 컬럼 검증을 실패하면 전체 변경을 거부합니다. 계산 오류는 셀과 의존 셀에 표시하며 원문을 수정하거나 Undo할 수 있습니다. 증분 의존성 그래프·워커 계산은 아직 없으므로 대량 수식은 호스트에서 규모에 맞춰 검증해야 합니다.

Ctrl+C는 Excel에 넣을 계산값 TSV와 MOUM 내부용 수식 payload를 제공합니다. 같은 수식 모드 그리드 간 붙여넣기는 상대 주소를 이동하고 `$` 주소를 고정합니다. 브라우저·중간 앱이 내부 형식을 제거하면 계산값만 전달됩니다. Excel에서 복사한 일반 HTML/TSV도 계산값을 입력합니다. `copySelection()`은 계산값 TSV를 반환합니다.

`GridModel.getData()`는 항상 원문입니다. `getComputedData()`는 계산값을, `formulaSheet().cell(row,col)`은 `{value,error}`를 반환합니다. `subscribe(listener)`는 반영 후 `{reason,changes,revision}`을 전달하며 반환 함수로 구독을 해제합니다. 직접 `model.rows`를 수정하면 이력·캐시·구독이 갱신되지 않으므로 변경 메서드를 사용하세요.

## XLSX 수식 보존

기본 내보내기는 계산값입니다. 원문 보존은 수식 모드에서 전체 원본 순서로 명시적으로 요청합니다.

```js
grid.exportXLSX({ scope: 'all', formulas: true, fileName: 'with-formulas.xlsx' });
await grid.importXLSX(file); // formulas:true 그리드는 수식을 기본 보존
await grid.importXLSX(file, { formulas: false }); // 캐시된 값만 가져오기
```

수식 가져오기는 시트가 A1부터 시작하고 모든 컬럼 순서가 같아야 합니다. 첫 행 헤더를 제거하면서 상대·절대 참조의 행 주소를 한 줄 낮추며, 내보낼 때는 한 줄 높입니다. 빈 행은 주소를 보존하기 위해 유지합니다. 데이터 헤더를 가리키거나 다른 시트를 참조하는 수식은 지원하지 않습니다. 수식 오류가 있는 파일 내보내기는 거부합니다. 파일은 원문과 계산 캐시를 포함하며 서식·보호·Excel 전체 계산 엔진을 재현하지 않습니다.

수식 보존을 끈 가져오기는 종전의 헤더 재배치 매핑을 사용합니다. 수식 캐시가 없거나 Excel 오류 셀이면 전체 가져오기를 거부합니다. 일반 문자열 `=...`의 안전한 텍스트 출력은 계속 유지됩니다.

## 한글 입력

IME의 Process/229 키에서 편집기를 준비하고 조합 중 입력 요소를 보존합니다. 조합 중 Enter·Tab은 셀 이동이나 커밋으로 처리하지 않고, 조합 완료 후 입력값을 한 번 반영합니다. 외부 provider가 편집 중 값을 변경하면 입력 원문을 보존하고 오래된 커밋을 거부합니다. Esc로 취소한 후 최신 데이터를 다시 편집할 수 있습니다.

Chromium CDP의 composition 입력 파이프라인으로 한글·Enter·Tab·Undo/Redo를 검사했습니다. 이 검사는 실제 Windows 한글 IME 후보창·자판 전환·브라우저별 이벤트 순서를 검증한 것은 아닙니다. 네이티브 IME·다른 엔진·스크린리더 수용시험은 남아 있습니다.

## 0.4 표시 방식과 엑셀 다운로드

로컬 페이징·무한 스크롤과 Excel 범위 선택은 [표시 방식 API](data-modes.md)에 정리했습니다. 이전 절의 전체 결과 기본 동작은 virtual 모드에 해당합니다.
